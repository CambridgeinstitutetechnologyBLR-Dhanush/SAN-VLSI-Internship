# Timing, Area & Power Review Checklist

- [x] RTL and target design identified.
- [x] Timing summary reviewed.
- [x] Critical input-to-output paths identified.
- [x] Setup and hold slack recorded.
- [x] Core area recorded from the metrics CSV.
- [x] DRC result checked.
- [x] LVS result checked.
- [x] Timing constraint limitation documented.
- [x] One timing risk identified.
- [x] One improvement proposed.
- [ ] Confirm power metric units and estimation methodology.
- [ ] Review the report against the original files before submission.
- [ ] Capture a screenshot of the timing summary or layout/report for evidence.

## Sign-off note
Do not claim validated power numbers until the units and estimation
assumptions have been confirmed.
